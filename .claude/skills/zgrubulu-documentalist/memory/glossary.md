# Glossaire — Hero Card Game

Termes propres au jeu, avec leur première source. Tenu à jour au fil des sessions (capacité `tenir-canon`).

- **L'Astronome** — système de modificateurs globaux de run, débloqué en cours de progression. Change la position des étoiles pour activer une "lune" (bonus + contrainte de combat). Source : GDD source (Google Doc), extrait le 2026-08-04.
- **Lune d'Or** — modificateur de l'Astronome : +50% de gain de ressources de village, +1 dégât subi. Source : GDD source, 2026-08-04.
- **Lune Vermeille** — modificateur de l'Astronome : plus de chances de cartes rares au loot, plus de chances d'élites en combat. Source : GDD source, 2026-08-04.
- **Cartes épiques** — type de carte (pas un palier de rareté) spécifique à une ou plusieurs classes, qui s'intègre temporairement au deck pour la durée d'un run. Source : GDD source, 2026-08-04.
- **Quête de classe / narrative / spéciale / multiple** — les 4 types de quêtes de la carte de run, chacun avec une règle différente de composition de troupe imposée. Source : GDD source, 2026-08-04. Détail : `_bmad-output/planning-artifacts/gdds/gdd-HERO-CARD-GAME-2026-08-04/gdd.md`.
- **Deck de run** — les 12 cartes (2 de base + 1 spéciale par héros × 4 héros) assemblées automatiquement au lancement d'un run ; distinct d'un deck construit librement par le joueur. Source : décision du 2026-08-04 (session GDD), résolvant un conflit entre 2 modèles trouvés dans les prototypes de code.
- **feuDeCamp** — écran de Run Infini, entre le draft de fin de combat et le combat suivant, à chaque combat. Choix entre "Repos" (soin/résurrection partiel, 20% des PV max, jamais un plein soin) et "Forge" (améliore 2 cartes aléatoires du deck vers leur version "+"). N'avance jamais le budget de difficulté. Nom canon choisi par le porteur de projet, repris tel quel dans le code (nom d'écran, nom du flux RNG dédié). Source : implémenté le 2026-08-10, revu le 2026-08-11. Détail : `gdd.md` → Système d'amélioration de cartes (feu de camp).
- **Carte "+"** — version améliorée d'une carte, obtenue via la Forge du feu de camp. Nom suffixé " +" (ex. "Coup direct +"). Une carte ne peut être améliorée qu'une seule fois. Source : 2026-08-10/11, voir `gdd.md` → Card Types and Effects.
- **Homme Arbre** — boss de fin de run borné (5 combats + 1 boss), aussi accessible seul via "Tester le boss" au menu. Toujours accompagné de 4 Pousses d'Arbre (composition fixe, jamais tirée par la génération aléatoire normale). Sensible au feu (+50% dégâts taggés "feu"), sa seule vraie faiblesse exploitable — indiqué par une ligne d'infobulle et une icône fixe dans son cadre. Source : implémenté 2026-08-21, sensibilité au feu ajoutée 2026-08-24. Détail : `gdd.md` → Boss de run borné — Homme Arbre.
- **Pousse d'Arbre** — sbire du boss Homme Arbre, PV faibles, une seule attaque faible. Toujours 4 sur le champ, jamais invoquées en cours de combat (Renaissance Sylvestre les ranime, n'en crée jamais de nouvelles). Source : 2026-08-21.
- **Main de feu** — carte de départ du Mage (ex-"Flamèche", renommée 2026-08-24). Dégâts magiques taggés "feu" — corrige un écart resté en place depuis la création de la carte (nom "feu" mais dégâts physiques/mêlée réels jusque-là). Déclenche la sensibilité au feu de l'Homme Arbre et bloque la Régénération du Troll des Marais si celui-ci est touché ce tour. Source : 2026-08-24.
